# آلة حاسبة بسيطة لأندرويد

مشروع Android أصلي بلغة Java، يعمل دون اتصال بالإنترنت بعد التثبيت.
الوظائف: الجمع والطرح والضرب والقسمة، النسبة المئوية، تغيير الإشارة، حذف آخر رقم، والأرقام العشرية.

## بناء APK
- افتح المشروع في Android Studio ثم نفّذ Build > Build APK(s).
- أو ارفع المجلد إلى مستودع GitHub، ثم افتح Actions وشغّل workflow باسم Build APK.
  بعد انتهاء البناء نزّل artifact باسم `calculatrice-apk`؛ داخله `app-debug.apk`.

ملاحظة: هذا ملف مشروع مصدر وليس APK جاهزًا. يحتاج إلى بناء APK بإحدى الطريقتين أعلاه.
